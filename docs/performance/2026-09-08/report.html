Priorities for follow-up

1. Validate the Mac render buffer's concurrent depth updates

RenderBridge stores depth in a plain count. Producer and consumer threads both modify it; the memory barriers do not make those read-modify-write updates atomic. Lost updates could affect depth, underruns and audio correctness. Use an atomic single-producer/single-consumer design and stress concurrent access before trusting its counters. AudioRenderer.swift:118, AudioRenderer.swift:147, AudioRenderer.swift:178.

2. Measure recovery after an audio burst

The Mac bridge holds up to 1,000 ms and evicts toward 800 ms only after exceeding 900 ms. Ordinary drift correction removes 20 ms at most once per five seconds above 120 ms. With matched input/output rates, reducing 800 ms to 120 ms needs 34 corrections, about 170 seconds. This is arithmetic from policy constants, not an observed delay. Test burst recovery separately from clock drift before changing the policy. AudioRenderer.swift:105, AudioRenderer.swift:577, DriftController.swift:24.

3. Profile capture callback tails before removing copies

Windows allocates a float input array, copies each pending group with GetRange().ToArray(), normalizes and encodes under synchronous callback execution. The measured processing cost is low, but the allocations and locks can produce GC or contention tails absent from the average. Profile individual callbacks during a long session before replacing these copies with a preallocated handoff. WasapiAudioCapture.cs:102, MicCaptureService.cs:209, ControlConnection.cs:601.

4. Bound pending work before the Mac renderer

Every incoming frame schedules an asynchronous renderer task retaining PCM, plus a coordinator task. The renderer's bounded ring only applies after those tasks execute. A stalled dispatch queue can therefore accumulate stale PCM outside that ring. Measure queue delay under a deliberate renderer stall; a bounded handoff may be warranted. ConnectionCoordinator.swift:564.

These are proposed follow-ups. No production implementation changed in this report.
